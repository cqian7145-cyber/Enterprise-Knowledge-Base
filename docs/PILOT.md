# 访谈与第一周试点计划

## 先拿到真实证据

分别访谈负责人1人、带教或当班主管2人、新员工2人、资深员工2人。每次20至30分钟。先询问最近一次具体经历，再展示原型；不要问“AI知识库是不是有用”。

1. 上一个班次新人问过哪些问题？能否拿出原聊天、纸质资料或现场记录？
2. 哪三个问题最常被重复问？谁回答，每次大约花多久？回答后还会不会返工？
3. 最近一次不同班次标准不一致发生在什么时候？当时依据哪份资料？谁确认最终版本？
4. 新人从入职到独立操作有哪些具体步骤？哪一步最慢？现有考核单和上岗确认人是谁？
5. 配方和流程现在放在哪？谁能修改？更新后怎么通知旧班次？哪些内容只允许部分岗位看？
6. 高峰期员工是否能使用手机？手机由谁提供？现场网络、戴手套和操作空间是否允许查询？
7. 哪些错误不可容忍？过敏原、设备与消防标准由谁签字确认？
8. 一周试点由谁维护资料、每天投入多久？如果验证有效，谁批准付费，预算从哪项成本中出？

每条发现记录：真实情境、原话／资料证据、发生频次、当前做法、负责人、损失或耗时、待验证假设。不把推测写成事实。

## 资料清单

优先收集10至20条高频真实知识，包括确认过的配方、开收吧、交接、服务标准。每条要有负责人、适用岗位／吧台、版本和生效日期；来源应是批准后的正式文档或明确书面确认。高风险资料不得由AI代写后直接上线。

## 第一周

| 天 | 工作 | 可检查交付物 |
| --- | --- | --- |
| 1 | 现场访谈与跟班，收集重复问题和旧资料 | 真实问题清单、来源及维护负责人 |
| 2 | 整理岗位／吧台授权和知识标准 | 10至20条经确认知识、权限表 |
| 3 | 导入草稿、负责人审核发布 | 员工可以查询并看到来源／版本 |
| 4 | 创建入职学习模块与实操验收表 | 至少1人完整完成阅读、答题、人工验收 |
| 5 | 用50条真实问题验收 | 标准答案、来源、未知、版本和权限边界结果 |
| 6 | 小范围真实班次使用，记录基线与问题 | 可比班次重复求助次数、现场障碍 |
| 7 | 修复错误和复盘，决定是否继续 | 错误清单、指标变化、维护成本与付费讨论 |

代码目前提供这条流程的基础工具，并不表示上述访谈、门店审批或班次试点已经完成。
