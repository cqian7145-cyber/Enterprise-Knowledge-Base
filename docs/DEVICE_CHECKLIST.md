## 每台计划支持设备逐项记录

- [ ] 登录／首次改密／会话过期可以恢复，密码交付不展示给无关人员。
- [ ] 竖屏与横屏无页面级横向溢出，菜单可找到；横向滚动菜单不遮住操作入口。
- [ ] 手指触控能选择吧台、门店和知识卡，按钮不易误触。
- [ ] 打开配方，关键数量、版本、来源和过敏提示可读。
- [ ] 弹窗可滚动、关闭，焦点与返回不丢失关键输入。
- [ ] 虚拟键盘弹出后，当前输入框和提交按钮仍可操作。
- [ ] 断网、恢复、真实弱网和请求超时有明确提示，不能诱发重复提交。
- [ ] 培训单选、提交、理论／实操状态可区分。
- [ ] 交接／异常证据输入可完成，不能由错误人员代替确认。
- [ ] 授权门店切换、撤权后返回本店可完成，不见其他门店资料。
- [ ] 高峰班次的实际灯光、屏幕位置、手部操作条件可接受，主要操作不要求繁复输入。
- [ ] 完整走E01–E12中适用路径，记录成功和失败；截图仅使用合成资料或已获授权的数据。
