## 用例覆盖

| 测试组 | 核验事项 |
| --- | --- |
| 身份与权限 | 匿名、员工／主管角色、门店、岗位、吧台、直接详情访问、CSRF和外域写请求 |
| 版本与定时生效 | 未发布不可见、未来版不抢先生效、新版替代、停用不恢复旧版、发布内容不可覆盖 |
| 过期和高风险 | 到期资料不可见；高风险发布要求确认 |
| 反馈 | 不能替其他用户提交反馈；引用版本留存；处理记录不改变配方 |
| 培训闭环 | 不泄露测验答案、作答检查、理论达标、实操需要主管确认、不可重复覆盖验收 |
| 培训失效 | 材料停用后阻止读取和测验，要求重新分配 |
| 任务与账号 | 范围校验、重复分配、创建账号、停用后会话失效 |
| 真实统计 | 查询数、人数、未匹配、门店隔离、退出登录 |
| 登录与输入 | 失败限流、拒绝额外身份字段、静态资源可访问、API不缓存 |
| 50题示例评测 | 30条名称／别名问法命中原文，20条未知和高风险无证据问题拒绝猜测 |

示例评测基于3项演示知识，含问法变体，**不能视为真实门店准确率达标**。测试期发现的英文别名空格匹配问题已修复。测试工具依赖出现一条Starlette针对httpx的弃用提示，不影响本轮通过；后续依赖升级时迁移对应测试传输适配。

## 仍需人工验收

1. 手机和桌面实际布局、键盘和屏幕阅读、弱网、登录过期、重复提交行为。
2. 真实配方逐字段核对，过敏原按实际供应商品复核。
3. 使用真实岗位／吧台矩阵及真实50题集合，重新核验泄露、版本与拒答。
4. 定时生效边界、运行中并发发布、数据备份和恢复。
5. TLS、Secure Cookie、反向代理和限流配置后开展小范围门店试点。
6. 正式主要指标需现场采集重复求助次数；没有预先编造效率改善百分比。
